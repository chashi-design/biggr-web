インクラインフロントレイズ

インクラインフロントレイズとは、ダンベルとインクラインベンチを使って「腕を前に上げる」動作で肩前部（三角筋前部）を鍛える種目です。可動域を確保しやすく、反動を使いにくいのが特徴で、肘を軽く曲げたまま肩の高さまで持ち上げ、ゆっくり下ろす動作を繰り返します。肩前部の筋力・筋量アップが期待できます。

動作方法

  1. 対象部位の力を抜かずに構える
  2. 反動を使わず、可動域を丁寧に使う
  3. 戻し動作をゆっくり行う

動作ポイント

  • 可動域を急に狭めない
  • 対象部位の緊張を保つ

ワンポイントアドバイス

  • 重量よりも肩の軌道を安定させる
  • 首まわりの力みを減らして行う

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。
