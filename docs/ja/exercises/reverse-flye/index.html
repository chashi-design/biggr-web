リバースフライ

リバースフライとは、ダンベルを使って「腕を開いて閉じる」動作で背中（広背筋、僧帽筋、菱形筋）＋腕（上腕二頭筋）を鍛える種目です。可動域が広く、左右のバランスを整えやすいのが特徴で、反動を抑えてコントロールしながら反復します。背中の厚み・広がり作りや姿勢改善が期待できます。

動作方法

  1. 体幹を安定させ、背中が丸まらない姿勢を作る
  2. 肘を後方へ引き、肩甲骨を寄せる
  3. 勢いを使わず、ゆっくり戻す

動作ポイント

  • 背中を丸めない
  • 首に力を入れすぎない
  • 戻しを速くしすぎない

ワンポイントアドバイス

  • 腕ではなく背中で引く感覚を優先する
  • 反動が増えたら重量を一段下げる

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。
