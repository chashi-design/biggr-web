フェイスプル

フェイスプルとは、ケーブルを使って「引く」動作で肩後部（三角筋後部）、僧帽筋、ローテーターカフを鍛える種目です。可動域全体で張力が抜けにくいのが特徴で、反動を抑えてコントロールしながら反復します。背中の厚み・広がり作りや姿勢改善が期待できます。

動作方法

  1. 体幹を安定させ、背中が丸まらない姿勢を作る
  2. 肘を後方へ引き、肩甲骨を寄せる
  3. 勢いを使わず、ゆっくり戻す

動作ポイント

  • 背中を丸めない
  • 首に力を入れすぎない
  • 戻しを速くしすぎない

ワンポイントアドバイス

  • 腕ではなく背中で引く感覚を優先する
  • 反動が増えたら重量を一段下げる

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。

1〜5回
筋肥大
6〜12回
持久力アップ
13〜20回
