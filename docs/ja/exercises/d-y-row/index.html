D.Y.ロウ

D.Y.ロウとは、ドリアン・イェーツの名に由来する背中を鍛えるマシンロウで、左右独立して動作できるアイソラテラル方式が特徴です。胸パッドに腹部をつけ、背中を伸ばした状態から肘を後ろへ引き、収縮を得て戻す動作を繰り返します。背中の厚みと広がり作りに効果的です。

動作方法

  1. 体幹を安定させ、背中が丸まらない姿勢を作る
  2. 肘を後方へ引き、肩甲骨を寄せる
  3. 勢いを使わず、ゆっくり戻す

動作ポイント

  • 背中を丸めない
  • 首に力を入れすぎない
  • 戻しを速くしすぎない

ワンポイントアドバイス

  • 腕ではなく背中で引く感覚を優先する
  • 反動が増えたら重量を一段下げる

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。
