ハムストリングカール(ライイング)

ハムストリングカール(ライイング)とは、マシンを使って「膝を曲げる」動作で太もも裏（ハムストリング）を鍛える種目です。軌道が安定して狙った部位に効かせやすいのが特徴で、かかとを引き寄せて収縮し、ゆっくり戻す動作を繰り返します。下半身の筋力・筋量アップが期待できます。

動作方法

  1. 足幅を決め、体幹を固める
  2. 股関節と膝を同時に曲げて下ろす
  3. 足裏全体で床を押して立ち上がる

動作ポイント

  • 膝とつま先の向きをそろえる
  • 胸を落としすぎない
  • かかとを浮かせない

ワンポイントアドバイス

  • ウォームアップで股関節と足首を動かす
  • 高重量の日はセーフティ設定を確認する

目的別回数設定
