ステップマシン

ステップマシンとは、マシンを使って「踏み台昇降のように踏み込む」動作を行い、主に下半身と心肺機能を鍛える有酸素トレーニングです。リズムよく続けやすいのが特徴で、左右交互に踏み込む動作を繰り返します。これにより、持久力向上や脂肪燃焼が期待できます。

動作方法

  1. ウォームアップで心拍を段階的に上げる
  2. 目的に合わせてペースを設定する
  3. 終了後はクールダウンで整える

動作ポイント

  • 呼吸を止めない
  • 開始直後に追い込みすぎない

ワンポイントアドバイス

  • 体調に合わせて時間や強度を調整する
  • ペースより継続を優先する

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。

筋力アップ
高強度 20〜60秒
筋肥大
中強度 10〜20分
持久力アップ
低〜中強度 20〜60分
