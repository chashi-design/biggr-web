ヒップアブダクション

ヒップアブダクションとは、マシンを使って「股関節を伸ばす」動作で臀部外側（中臀筋など）を鍛える種目です。軌道が安定して狙った部位に効かせやすいのが特徴で、反動を抑えてコントロールしながら反復します。股関節の安定とヒップラインの改善が期待できます。

動作方法

  1. 対象部位の力を抜かずに構える
  2. 反動を使わず、可動域を丁寧に使う
  3. 戻し動作をゆっくり行う

動作ポイント

  • 可動域を急に狭めない
  • 対象部位の緊張を保つ

ワンポイントアドバイス

  • ウォームアップで股関節と足首を動かす
  • 高重量の日はセーフティ設定を確認する
