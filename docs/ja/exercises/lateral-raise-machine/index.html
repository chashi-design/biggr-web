ラテラルレイズマシン

ラテラルレイズマシンとは、マシンを使って「腕を横に上げる」動作で肩中部（三角筋中部）を鍛える種目です。軌道が安定して狙った部位に効かせやすいのが特徴で、反動を抑えてコントロールしながら反復します。肩幅を作り、逆三角形のシルエットづくりが期待できます。

動作方法

  1. 対象部位の力を抜かずに構える
  2. 反動を使わず、可動域を丁寧に使う
  3. 戻し動作をゆっくり行う

動作ポイント

  • 可動域を急に狭めない
  • 対象部位の緊張を保つ

ワンポイントアドバイス

  • 重量よりも肩の軌道を安定させる
  • 首まわりの力みを減らして行う

目的別回数設定

目的や体力に応じた一般的な目安です。無理のない範囲で調整してください。

6〜12回
